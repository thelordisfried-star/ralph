## 2024-07-21 - [Optimize React Flow Graph State Resetting and Visibility]
**Learning:** Re-creating React Flow `initialNodes` and `initialEdges` entirely from scratch during graph traversal or state updates (like "Next", "Prev") forces the library to discard its internal positioning state, causing components to re-render slowly and lose layout properties.
**Action:** Instead of constantly rebuilding the node array, pre-compute essential metadata (`stepIndex`, `sourceIndex`, `targetIndex`) onto the nodes' `data` objects during initial creation. Then, strictly use functional updates via `setNodes(nds => nds.map(...))` to selectively toggle the standard CSS `style` properties (like `opacity` and `pointerEvents`) only when necessary. This preserves referential identity and allows `React.memo` to skip unmodified components, vastly improving layout speed and solving layout resets.
