## 2024-10-30 - Removing React Flow Full Node Array Recreations
**Learning:** In React Flow, entirely replacing the `nodes` array instead of using functional updates (`setNodes(nds => nds.map(...))`) destroys internal states such as node coordinates updated by user drag events. This forced the application to manually sync and track all coordinates in a `useRef` hook (`nodePositions`) across the `onNodesChange` and `handleNext`/`handlePrev` functions, adding unnecessary complexity and computational overhead for a simple UI interaction.
**Action:** When updating node styles (like opacity or pointerEvents) during state transitions, always use functional state mapping `setNodes(nds => nds.map(n => ({...n, style: {...}})))`. This updates properties directly on existing nodes while safely preserving React Flow's internal state mapping and rendering, completely eliminating the need for manual `useRef` coordinate tracking and full array recreation.
