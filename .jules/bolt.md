## 2024-05-24 - React Flow Internal State and Array Updates
**Learning:** In React Flow, when updating node styles (like opacity for visibility) based on user interaction (like pressing Next/Prev), you must use functional state updates (e.g., `setNodes(nds => nds.map(...))`) instead of completely re-creating the nodes array (e.g., `setNodes(getNodes(newCount, nodePositions.current))`). Complete re-creation of nodes overwrites internal state, destroying user-initiated position changes (node dragging) and requiring an expensive O(N) re-creation of all node objects. Additionally, O(N) array methods inside map callbacks cause O(N^2) time complexity, and thus Maps should be pre-computed outside of the component loop.
**Action:** Always prefer functional state updates for arrays (`setState(prev => prev.map(...))`) over total replacement when only a subset of object properties (like styling/visibility) needs modification, preserving internal state and reducing memory allocation overhead.
