## 2026-04-15 - [React Flow Functional State Updates]
**Learning:** In React Flow, entirely re-creating the \`nodes\` and \`edges\` arrays from scratch on every state update (e.g. for visibility toggling) destroys the internal node state within the library, breaking native features like node positioning after panning/dragging. This forces brittle workarounds like tracking x/y coordinates via manual \`useRef\` syncing.
**Action:** When updating React Flow elements to toggle visibility or styling, always use functional state updates (e.g., \`setNodes(nds => nds.map(...))\`) and return the original element reference (e.g., \`if (noChange) return node;\`) if unchanged. This preserves referential stability, allowing React Flow to natively maintain dragged positions and optimized internal state without external tracking.
