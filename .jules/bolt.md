## 2024-05-24 - React Flow Performance Optimization
**Learning:** Recreating entire node and edge arrays from scratch on every state update (e.g., during "next" or "prev" steps) discards React Flow's internal node state. This forces the use of a brittle ref workaround (`nodePositions.current`) to track dragged positions manually and causes O(N) object allocations and full re-renders for every step change.
**Action:** Use functional state updates (`setNodes(nds => nds.map(...))`) to selectively update properties (like visibility styles) of existing nodes. Embed static metadata (`stepIndex`, `appearsWithStep`, etc.) into the node/edge `data` objects during initial creation for O(1) lookups instead of module-level Map lookups. This preserves referential equality of unmodified nodes/edges and allows native React Flow internal state preservation.
