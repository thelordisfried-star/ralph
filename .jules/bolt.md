## 2024-07-26 - React Flow Edge Visibility Styles Optimization
**Learning:** When using functional state updates to optimize React Flow edge visibility, do not blindly set `opacity: 0` for "inactive" edges if the original code didn't. In the original implementation, edges were shown/hidden by toggling `animated` and `label` while leaving the underlying solid line visible. Setting `opacity: 0` on edges entirely hid them, creating a visual bug compared to the original code.
**Action:** When migrating complex React component arrays to functional updates, carefully inspect the original property manipulation map. Instead of adding general style overrides like `opacity: 0` for edges, preserve exactly the subset of properties (like `animated` and `label`) that the original map toggled.
