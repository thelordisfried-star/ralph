## 2023-10-27 - React Flow Functional State Updates preserve internal Coordinate State
**Learning:** In React Flow, entirely replacing the nodes array with a newly computed one on external state changes (like next/prev clicks) overwrites internal coordinate modifications resulting from user drag and pan interactions. Manually tracking `nodePositions` via a `useRef` to reconcile coordinates on drag creates unnecessary rendering overhead and O(N) object updates.
**Action:** Transition away from full object re-creations (`getNodes`) in favor of functional state updates (`setNodes(nds => nds.map(...))`). By only mutating target properties (`opacity` and `pointerEvents`), React Flow naturally preserves internal layout state, eliminating the need for `useRef` coordinate tracking.
