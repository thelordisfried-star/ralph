## 2023-10-27 - React Flow Array Recreation Bottleneck
**Learning:** In React Flow, re-creating the entire `nodes` array (via an O(N) factory function) on every state change destroys internal node state like drag positions, forcing the app to manually track positions using a `useRef` and `onNodesChange`. It also causes severe rendering overhead since React Flow has to process new object instances for every node.
**Action:** Always use functional state updates (`setNodes(nds => nds.map(...))`) for visibility or style toggles. Include an explicit referential equality check (e.g., `if (node.style.opacity === newOpacity) return node;`) to preserve object references for unchanged elements, thereby maintaining internal state and reducing re-renders. Use `Map`s for O(1) lookups to avoid O(N) array traversals inside the map callback.
