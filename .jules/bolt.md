## 2025-02-18 - React Flow Internal State Destruction via Array Recreation
**Learning:** When using React Flow (`@xyflow/react`), completely recreating the `nodes` array during step changes via a factory function (e.g., `getNodes()`) implicitly destroys React Flow's internal state for those nodes. This includes position data updated by user drag events. This forced the original author to manually track positions in an O(N) loop during `onNodesChange` and save them to a `useRef` to inject back into the factory function.
**Action:** When updating React Flow state incrementally (like stepping through a flow or toggling visibility), always use functional state updates and map over the existing nodes array (e.g., `setNodes(nds => nds.map(...))`). This preserves the internal state (like dragged positions) automatically, eliminating the need for manual tracking overhead during high-frequency drag events.
