## 2024-08-04 - React Flow Node Visibility Re-rendering Optimization
**Learning:** In the `flowchart` application, modifying the number of visible steps previously required re-creating the entire node and edge arrays using `getNodes()` on every state update. This causes React Flow to discard internal node state and re-initialize dimensions, leading to performance bottlenecks during interactions.
**Action:** Always use functional state updates (e.g., `setNodes(nds => nds.map(...))`) and embed necessary metadata directly inside `node.data` / `edge.data` initially. Check current property values (e.g., `if (node.style?.opacity === opacity) return node;`) to selectively update visibility properties. This preserves referential equality of unchanged elements and utilizes React Flow's native optimization for rendering.
