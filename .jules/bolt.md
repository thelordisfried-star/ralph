## 2024-09-06 - Replacing O(N) array recreation with functional state updates in React Flow
**Learning:** Completely recreating the `nodes` and `edges` arrays via `getNodes` on every step change destroys React Flow's internal state (like user-dragged node positions). Although the codebase used a `useRef` to manually re-apply these positions, it caused O(N) unnecessary object allocations and a heavy re-render. Worse, using O(N) `.find()` methods inside a `.map()` during state updates introduces O(N^2) complexity, significantly degrading performance on larger graphs.
**Action:** When updating node or edge properties like visibility, use functional state updates (`setNodes(nds => nds.map(...))`) and check for equality (`if (node.style?.opacity === newOpacity) return node`) to preserve referential equality and skip unnecessary renders. Avoid O(N) lookups inside `.map()` by precomputing maps or directly utilizing edge `.source` and `.target` properties.
