## 2025-02-12 - React Flow Functional State Updates Optimization
**Learning:** In React Flow, re-creating entire node and edge arrays from scratch on every state update (e.g., during pagination or stepping) forces the library to discard internal element state and continuously re-initialize dimensions and event handlers. This leads to heavy O(N) array recreation and DOM thrashing, breaking internal features like pan/zoom unless brittle workarounds (like manual ref-tracking for positions) are used.
**Action:** Always use functional state updates (`setNodes(nds => nds.map(...))`) to selectively update properties (like `style.opacity` or `style.pointerEvents`) of existing elements rather than fully recreating them. Furthermore, embedding metadata (like `stepIndex`) directly into the element's `data` payload allows for fast O(1) state resolution within the functional setter, eliminating the need for external lookup maps or continuous full-graph reconstructions. Returning the original unmodified element object when style values haven't changed further optimizes React reconciliation.
