## 2025-02-12 - Functional vs Reference state updates for React Flow elements
**Learning:** In React Flow, re-creating entire node and edge arrays from scratch on every state update (e.g. tracking positions using `useRef` and passing new coordinate objects via `getNodes`) forces the library to discard internal node state and re-initialize dimensions, leading to brittle workarounds like tracking x/y coordinates via refs. This also causes major lag as panning/zooming re-renders every item.
**Action:** Always use functional state updates (e.g., `setNodes(nds => nds.map(...))`) to selectively update style properties (like visibility) of existing nodes/edges to preserve referential stability, internal state, and positioning natively. This completely removes the need to track node positions manually with `useRef`.
