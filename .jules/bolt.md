## 2024-06-01 - React Flow Array Recreation Bottleneck
**Learning:** In `@xyflow/react`, completely recreating the `nodes` and `edges` arrays via `getNodes()` inside step handlers forces React Flow to diff the entire array, potentially recalculating bounds and breaking referential equality for all elements. This is an O(N) operation that scales poorly and causes unnecessary re-renders during state toggles.
**Action:** Use functional state setters (`setNodes(nds => nds.map(...))`) to selectively mutate only the specific visual properties (`opacity`, `pointerEvents`, `animated`, `label`) of the existing elements. Combine this with an early return (`if (node.style?.opacity === opacity) return node;`) to perfectly preserve referential equality for elements whose visibility state hasn't changed.
