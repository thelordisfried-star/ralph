## 2024-05-30 - Optimized React Flow Visibility Toggling
**Learning:** React Flow elements completely lose their internal references, position states, and cause full reconciliations if they are recreated completely in functional setters (e.g., mapping `createEdge` instead of updating styles). Replacing array recreation with mapping over existing arrays to only modify `style.opacity` and `pointerEvents` prevents position loss during dragging/panning and massively improves performance by leveraging React Flow's native memoization.
**Action:** When updating visibility or styles in React Flow, always map over the *existing* elements from functional state setters (like `setNodes(nds => nds.map(...))`) and only merge specific updated properties (like `style`). Never recreate node objects from scratch using helper functions inside step callbacks.
