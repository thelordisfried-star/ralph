## 2023-11-20 - [Optimize Ref Recreation in React Flow]
**Learning:** In a React Flow application using large data models, wiping out state using `useRef` directly impacts rendering stability and requires an extensive array of new elements to be recreated per user interaction. Furthermore, storing and mutating DOM node positional mappings within an `useRef` disrupts native React Flow referential stability and requires more computationally expensive array recreations on every step navigation interaction.
**Action:** Replace `nodePositions` and structural `setNodes` mapping with targeted property mutations (`opacity` and `pointerEvents`) using spreading operators to avoid complete reallocation. Avoid parsing ids; use lookup tables (`noteAppearsMap` and `stepIndexMap`) instead to evaluate visibility natively in O(1). Use functional setters to selectively toggle visibilities and restore hidden original property tags (like labels and edge strokes) cleanly from an `edge.data` reference when reactivating the display elements.
