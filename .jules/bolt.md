## 2024-05-02 - React Flow Graph State Stability Optimization
**Learning:** In @xyflow/react, mapping over data constants to build node and edge arrays on every interaction (e.g., in a `handleNext` function) destroys referential stability, leading to expensive full-graph re-renders and potential performance bottlenecks. Using inline objects for configuration props like `fitViewOptions={{ padding: 0.2 }}` also exacerbates internal re-renders.
**Action:** When mutating complex React Flow structures like visibility on user interaction, extract configuration props to module-level constants. Instead of recreating nodes/edges from scratch, use functional state setters (`setNodes(nds => ...)`) to iterate over the existing state, selectively mutating only properties like `style.opacity` with object spread (`...node, style: { ...node.style, opacity: 1 }`). This maintains referential stability for unchanged nodes and efficiently triggers targeted updates.
