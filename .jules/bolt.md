## 2024-08-16 - Functional State Updates for React Flow Elements
**Learning:** Completely recreating the `nodes` and `edges` arrays on every interaction (e.g., using `edgeConnections.map` to generate new objects from scratch) causes unnecessary O(N) object allocations and forces React Flow to re-evaluate the entire graph structure, causing a performance bottleneck during interactions like step transitions.
**Action:** When updating element visibility or styles, use functional state updates (e.g., `setNodes(nds => nds.map(...))`) and mutate only the required properties (like `opacity` or `pointerEvents`), returning the original element unchanged if the target state already matches. Embed metadata inside the element's `data` object for O(1) checks during the map operation to avoid costly `find()` lookups or map recalculations.
