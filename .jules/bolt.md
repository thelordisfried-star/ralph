## 2025-02-19 - React Flow Node Optimization
**Learning:** React Flow internally re-renders nodes frequently on pan/zoom actions. Creating inline objects for node props (like `style` or `data`) combined with missing `React.memo()` on custom nodes destroys referential stability, leading to significant GC pressure and performance drops as the graph scales. Additionally, passing `nodePositions.current` (a ref) directly into a `useMemo` block initializer triggers strict ESLint `react-hooks/refs` errors, as it accesses a ref value during render.
**Action:** Always pre-compute static data objects outside the React component (using `reduce` over `map` arrays if possible for O(1) lookups), wrap all Custom/Note node components in `React.memo()`, and extract all style objects and config props to module-level constants. When initializing `useMemo` for static values, reference module-level constants instead of React `useRef().current` values.
