## 2024-08-07 - Functional State Updates and Metadata Embedding in React Flow
**Learning:** In React Flow, re-creating entire node and edge arrays from scratch on every state update (e.g., using a map to create new nodes) forces the library to discard internal node state, re-initialize dimensions, and leads to O(N) object allocations on every step.
**Action:** Avoid full array recreations. Embed metadata (`stepIndex`, `appearsWithStep`, `sourceIndex`, `targetIndex`, `originalLabel`) directly into the `data` object of nodes and edges at initialization. Then, use functional state updates (`setNodes(nds => nds.map(...))`) to selectively update style properties (like opacity) of existing elements, returning unmodified elements if properties match to preserve referential equality and maximize rendering performance.
