## 2023-10-25 - React Flow Functional State Updates with Metadata
**Learning:** When dynamically hiding/showing elements in a React Flow application (like stepping through a flowchart), generating entirely new arrays of nodes and edges on every step using functions like `getNodes` forces O(N) recreations and triggers massive re-renders across the entire canvas, even when wrapped in `React.memo`.
**Action:** Embed constant lookup metadata (e.g., `stepIndex`, `originalLabel`) directly into the element's `data` object during initialization. Then, use functional state updates (`setNodes(nds => nds.map(...))`) to toggle properties like `opacity`, returning the original element unmodified if the computed state matches the current state. This preserves referential equality and drastically reduces React rendering overhead.
