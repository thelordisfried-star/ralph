## 2025-02-28 - React Flow Opacity vs Native Hidden Property Performance
**Learning:** Initially attempted to refactor array generation logic to mutate styles like `opacity: 0` directly using `.map()` functional updates. While this preserved internal coordinate state during user drag events, it caused a critical performance regression because React Flow was forced to render and measure invisible nodes continuously within the DOM. Furthermore, inlining complex array lookups inside the mapping loops introduced O(N^2) overhead, breaking the core node spawning mechanics if the original generator filtered arrays.
**Action:** Always prefer utilizing React Flow's native `hidden: true` property at the creation/generator level. This instructs the library to physically unmount the invisible nodes/edges from the DOM while preserving their definitions in state, eliminating DOM bloat and avoiding complex state synchronization bugs entirely.
