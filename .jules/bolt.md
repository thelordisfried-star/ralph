## 2023-10-27 - [Preserve React Flow Internal State with Functional Setters]
**Learning:** [In React Flow, re-creating entire node and edge arrays from scratch on every state update (e.g., during "Next" or "Prev" steps) forces the library to discard internal node state and re-initialize dimensions, which requires brittle workarounds like tracking x/y coordinates via refs. This causes high memory overhead, garbage collection pressure, and subtle bugs like loss of edge label configurations.]
**Action:** [Always use functional state updates (e.g., `setNodes(nds => nds.map(...))`) to selectively update properties (like visibility styles) of existing nodes and edges. This preserves internal state and positioning natively, eliminating the need for `useRef` to manually synchronize positions.]
