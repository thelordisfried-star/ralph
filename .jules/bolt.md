## 2023-10-27 - React Flow State Visibility Optimization
**Learning:** In React Flow, entirely recreating the nodes and edges array (e.g., using `getNodes`) on every state change forces React Flow to diff the entire dataset, creating significant garbage collection pressure and breaking memoization. Additionally, updating `data: { ...node }` isn't always necessary for visibility; the original architecture mapped visibility purely to `style` (opacity/pointerEvents) rather than relying on a `data.isVisible` prop passing down to custom components.
**Action:** Always optimize React Flow state changes by using functional setters `setNodes(nds => nds.map(...))` to selectively mutate existing objects, pulling external style objects into module-level constants to preserve referential stability. When mapping visibility, rely on Map lookups (O(1)) instead of array scans.
