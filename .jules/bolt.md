## 2024-10-27 - [Optimization of React Flow state updates]
**Learning:** When using state array recreations (e.g., re-mapping raw configurations to `Node` and `Edge` objects on every action), React Flow loses referential equality for all items, leading to large rendering overhead and lost user interaction state (e.g. dragging changes). Furthermore, filtering array states in functional updates can be very slow if it requires `find` loops across external maps.
**Action:** Always embed structural metadata (like step index mapping or source/target steps) directly in the `data` field of React Flow elements during initial creation. Then, during state updates, use functional updates (`nds.map(...)`) combined with a quick O(1) attribute check (`node.style?.opacity === targetOpacity`) to return the unmodified exact object reference when visuals haven't changed, avoiding unnecessary React and React Flow re-renders.
