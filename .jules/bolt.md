## 2024-05-18 - [Optimizing React Flow Renders in flowchart/src/App.tsx]
**Learning:** In the React Flow `App.tsx` component, constant prop objects like `fitViewOptions={{ padding: 0.2 }}` and `deleteKeyCode={['Backspace', 'Delete']}`, as well as dynamically generating style/data objects inside `createNode` and `createNoteNode`, completely break `React.memo` benefits because they create brand new object references every render. This forces full re-renders of the canvas when interacting with React Flow (e.g., panning or zooming) even when node contents didn't change. Also, ESLint strictly prohibits reading refs (e.g. `nodePositions.current`) during `useMemo` computation since refs shouldn't be read during the render phase.
**Action:** When working with React Flow (and React generally), always hoist static node properties, inline arrays/objects, and style definitions (`CSSProperties`) to module-level constants or pre-create data structures like `stepDataMap` outside of the render cycle. If memoized default values are needed, rely on those static constants instead of refs to initialize the graph.
