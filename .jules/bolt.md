## 2024-05-15 - [Optimization: functional node updates and mapping]
**Learning:** Found an opportunity to improve the `flowchart` rendering by avoiding recreating the entire React Flow node and edge arrays on every step. React Flow performs better when we modify object properties (like `opacity` or `pointerEvents`) using functional updates (`setNodes(nds => nds.map(...))`) instead of recreating them from scratch via helper functions (`getNodes`). The initial arrays can also be reused instead of recalculating during a reset.
**Action:** Replace `getNodes` recreations with state mutations that preserve React Flow's internal state (like drag positions). Use mapping tables outside of the component for faster lookups. Ensure `node_modules` cleanup when running checks locally.
