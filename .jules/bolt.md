## 2024-05-18 - [Optimizing React Flow Render Cycles with Functional Setters]
**Learning:** [In a React Flow app (`App.tsx`), calling `setNodes` and `setEdges` with entirely new arrays on every state change causes O(N) object recreations. This forces React Flow to do deep equality checks and internal re-renders for every node/edge, even if only a few changed visibility, leading to performance stutter and loss of user-dragged node positions.]
**Action:** [Use functional state updates (`setNodes(nds => nds.map(...))`) to selectively mutate only the `style` properties of nodes/edges whose visibility actually changed. By returning the exact same object reference for unchanged elements, React bails out of re-rendering them entirely, turning an O(N) operation into an O(1) impact for unchanged nodes, drastically improving animation smoothness and preserving internal state like pan/zoom/drag.]
