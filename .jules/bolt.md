## 2024-03-24 - Optimizing React Flow Graph Updates
**Learning:** Recreating node and edge arrays on every state change (e.g., `setNodes(getNodes(...))`) destroys React's referential equality for unchanged items in React Flow. This forces a complete remount/re-evaluation of the graph, making simple style updates (like opacity) unnecessarily expensive (O(N)). Also, missing `React.memo` on custom node components triggers full re-renders whenever internal graph state (like pan/zoom) updates.
**Action:** Always use functional state setters (`setNodes(nds => nds.map(...))`) to selectively mutate only the specific properties (e.g., `style`, `animated`) of existing nodes/edges that change. Ensure custom node components (`CustomNode`, `NoteNode`) are wrapped with `React.memo` at their definition to bypass re-renders during React Flow internal interactions.
