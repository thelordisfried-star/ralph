## 2024-08-08 - React Flow State Updates
**Learning:** Re-creating entire node and edge arrays from scratch on every state update in React Flow forces the library to discard internal node state and re-initialize dimensions. This requires brittle workarounds (like tracking x/y coordinates via refs) and incurs unnecessary rendering overhead.
**Action:** Always use functional state updates (`setNodes(nds => nds.map(...))`) to selectively update properties (like visibility styles) of existing nodes/edges to preserve referential equality and internal state natively. Embed O(1) lookup metadata directly into node/edge `data` payloads.
