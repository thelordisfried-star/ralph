# Claude Code Setup Assistant 🚀

Your interactive guide to becoming a Claude Code power user! This dashboard-style app walks you through step-by-step to set up the best skills, MCP servers, settings, hooks, git workflows, and productivity tips.

## What It Does

This app teaches you THE BEST WAYS to setup Claude Code with:

- 🎯 **Essential Skills** - Must-have skills with copy-paste install commands
- 🔌 **MCP Servers** - Best servers for different use cases
- ⚙️ **Settings & Config** - Optimal settings.json setup
- 🪝 **Hooks & Automation** - Useful hooks to supercharge your workflow
- 📁 **Git Best Practices** - Recommended git workflows
- 🤖 **Agent Templates** - Pre-built agent configs
- ⚡ **Productivity Tips** - Get the most out of Claude Code

## Features

### Dashboard Style with Step-by-Step Flow
- See ALL setup categories at once (dashboard view)
- Progress through them step-by-step with navigation buttons
- Jump to any section you want
- Track progress with checkboxes
- **Copy-paste commands** ready to go

### What Makes Each Item Special
- ✅ Checkboxes to track what you've completed
- 📋 One-click copy buttons for all commands/code
- 💡 Clear "WHY it matters" explanations
- 🔴🟡⚪ Priority labels (Essential/Recommended/Optional)
- 🔗 Links to documentation
- 📊 Progress tracking across all sections

### Interactive & Beautiful
- Modern dark theme with gradients
- Smooth animations
- Responsive design
- Progress bar showing completion percentage
- Persistent progress (saves in localStorage)

- React 19 with TypeScript
- Vite for blazing fast development
- Framer Motion for smooth animations
- Modern CSS with gradients and glassmorphism

## How It Works

1. **Dashboard Navigation** - Cards showing all 7 setup categories with completion counts
2. **Step-by-Step Content** - Each section shows items with descriptions, commands, and why they matter
3. **Progress Tracking** - Check off items as you complete them, saves automatically
4. **Copy & Paste** - One-click copy for all commands and code snippets
5. **Navigate Freely** - Use Next/Previous buttons or jump directly to any section
