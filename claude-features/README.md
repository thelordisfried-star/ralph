# Claude Features Explorer

An interactive web app that helps users discover and understand Claude's capabilities in a creative, engaging way.

## What it does

This app presents Claude's features as an interactive constellation of cards, where each feature is organized by category and includes:

- **What**: Clear explanation of what the feature does
- **Why**: The value and reasoning behind why it matters
- **Examples**: Real-world use cases

## Features

- **Category Navigation**: Browse features by category (Coding, Analysis, Creative, Productivity, Advanced)
- **Search Functionality**: Quickly find specific features
- **Interactive Cards**: Click any feature to see detailed information
- **Beautiful UI**: Modern, gradient design with smooth animations
- **Responsive**: Works on desktop, tablet, and mobile devices

## Why this matters

Users often don't know what's possible with AI. This app:

1. **Reduces Discovery Friction**: Users can explore features without reading long documentation
2. **Explains Value**: Each feature includes "why it matters" so users understand the benefit
3. **Inspires Usage**: Seeing all capabilities in one place sparks ideas for new use cases
4. **Organizes Complexity**: Categories make it easy to find relevant features
5. **Engaging Experience**: Beautiful design makes learning about features enjoyable

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Tech Stack

- React 19
- TypeScript
- Vite
- Framer Motion (animations)
- CSS3 with gradients and modern effects

## Design Philosophy

The app uses a constellation metaphor because:

- Features are like stars in the sky - numerous and bright
- Categories are like constellations - they give structure and meaning
- Exploring should feel like discovery, not reading a manual
- Each feature deserves its moment to shine
